训练任务

通过本地 Python 服务运行 `TrainingManager`。每个 episode 都会落盘为可回放产物，并在训练结束后保存 `best` 与 `final` 两组模型。

训练 episode 时长仍使用当前工作区 `config.py` 中的 `EPISODE_DURATION`。页面仅负责触发任务、管理模型和展示运行产物，不新增后端未支持的训练输入项。

测试任务

选择当前项目中的模型组进行 deterministic 推理测试。每个测试 episode 都会保存独立回放，可直接在下方列表中切换。
